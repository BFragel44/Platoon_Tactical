# Veteran Typewriter

Font by Koczman Balint, supplied by the user in `veteran-typewriter.zip` from
1001 Fonts (https://www.1001fonts.com/typewriter-fonts.html).

The archive's original `license1.txt` is included unchanged. It permits personal
and commercial use and prohibits selling the font directly.

Bundled locally for the beige command-desk preparation screens; no external
font service or network request is required. Courier New / monospace provides
the fallback while the font loads.
