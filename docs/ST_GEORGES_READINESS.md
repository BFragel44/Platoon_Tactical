Only artwork was read; no downloaded code was executed. The supplied Normandy p.13 equipment/XP tables were rendered and visually verified October 7: eight handheld illumination devices, no field phones for combat patrols, and patrol-specific 4/1/5 XP. The p.24 instruction says two Row 1 Foxholes per card, while the p.25 key says up to two; use two as the default and retain the source distinction when authoring optional setup.
